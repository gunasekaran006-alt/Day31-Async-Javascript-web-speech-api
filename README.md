# Speech to Text Web App 🎙️

A simple, modern, and responsive web application that converts real-time speech into text using the browser's native [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API).

## ✨ Features
* **Real-time Transcription**: See your speech converted to text instantly as you speak.
* **Interim Results**: Differentiates between "processing" text and "final" confirmed text.
* **Modern UI**: Clean, card-based design with interactive button states.
* **Browser-Native**: No external libraries or API keys required.
